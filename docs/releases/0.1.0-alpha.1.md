# Greg ULV Expansion 0.1.0 Alpha 1

首个公开 Alpha，为 GTCEu Modern 7.5.3 / Minecraft 1.20.1 Forge 提供完整的 ULV 过渡阶段。

## 内容

- 手摇发电机、温差发电机、红石发电机、ULV 燃气轮机与铅酸储能线。
- ULV 马达、活塞、传送带、泵、机械臂、流体调节器，以及配套基础机器。
- 铅室法制酸装置、最高 6 层的原始蒸馏塔、原始裂化机与青铜框架流体钻井机。
- 从原油、乙烯到聚乙烯，以及天然橡胶到橡胶成型的完整早期路线。
- 简体中文机器名、tooltip 和 EMI 配方分类。

## 本次修正

- 单方块机器统一采用与上游一致的命名和 tooltip 模板，仅保留 ULV 数值差异。
- 基础构件的配方形式与上游一致，并补齐三种橡胶材料路线。
- 修正多方块结构、钢制燃烧室替代、蒸馏塔高度上限及钻井机青铜框架。
- 简化蒸馏塔框架等结构方块贴图与模型引用。
- 修正手摇发电机无曲柄产电、曲柄无法安装及破坏时错误掉落的问题。
- 显式固定 ULV 泵与流体调节器为 16 mB/t，避开上游 tier 0 公式的整数截断。

## 验证

- Forge GameTest 覆盖手摇交互、曲柄掉落、配方完整性、本地化、tooltip、关键数值和四台多方块的实际成型。
- `runData`、`runGameTestServer` 与 `clean build` 全部通过。

必需前置：GregTech CEu Modern 7.5.3。该版本为预发布版本，存档升级前请保留备份。
