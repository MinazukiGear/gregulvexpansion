## 归档：问题背景与方案权衡（裁决依据）

### A1. 小型蒸汽轮机的存亡 → 裁决：砍除

上游 LV 蒸汽轮机（32 EU/t、64 mB/t）造价不高，存在被玩家直接跳造的风险；所有者裁定不赌实测结果，直接移除。蒸汽变现语义由温差/红石发电机与铅酸蓄电墙承接，姊妹项目蒸汽联动收窄为「铅室消费蒸汽」。

### A2. ULV 洗矿机的越级边界 → 裁决：砍除

承接「不纯尘→纯净尘」会把矿物链第二步下沉到 ULV，破坏「LV 才洗矿」的升级阶梯；所有者裁定不冒此险。ULV 产线收缩为线材轧机 + 切割机 + 原型电解槽，热离心/筛选维持 LV（红线 §3.4）。

### B1. PbO₂ 氧化路径 → 裁决：电解槽阳极氧化

三方案（电解槽阳极氧化 / 新专用机器 / 工作台合成）中选定电解槽路线：历史上电解确曾制 PbO₂；顺序为手摇（零门槛）→ 电解槽（本体零电可造）→ PbO₂ → 铅酸电池，电解槽因此成为储能链前置、提为 P1 首位。

### D2 / D14 / D15 裁决补充说明

- **D2**：木质曲柄恢复为独立物品（v0.1 曾倾向合并），并追加 AE2 木质曲柄软兼容——实现时以 ModList 探测 AE2，不做硬前置。
- **D14**：替代配方从 P3 提为 P2 并**禁用上游原配方**（`IGTAddon#removeRecipes` 移除真空管/NAND 官方配方）。此裁决突破了总纲「不修改上游」红线，总纲 §3.5 已修订为「默认新增并存；所有者明示裁决时可移除指定上游配方」。影响：探测器成为 ULV 电路唯一入口，方铅矿→探测器链地位上升（D13 因此保持 ×2 产出对冲）。
- **D15**：马达前置从「仅用电机器」扩展到「温差/红石发电机」，原「电子/机械语义分线」理由作废，统一为「马达 = 一切带电动部件设备的公共前置」；手摇发电机经补充确认保持例外（零电门槛）。
