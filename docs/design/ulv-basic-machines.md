# ULV 机器下沉（ULV 洗矿机 / 线材轧机 / 切割机）设计规格

> 状态：**未定案（草案 v0.2，2026-09-07）** · 优先级：**P1** · 类型：单方块 ULV 机器（上游机器的层级变体，配方子集）
>
> 变更记录：v0.2 移除硒整流器前置（硒材料弃用），三机合成前置改为超低压电动马达（见 [ulv-components.md](ulv-components.md)，P0 构件线）。

## 定位

把上游 LV 机器中「语义上并不高压」的三种，以**显式配方子集**的方式下沉到 ULV，让微电网有活干，同时保住 LV 的升级诱惑。

- 统一机制：三台机器全部使用**独立配方类型**（各自的新 RecipeMap），只收录本文档明确列入的配方；不挂上游配方表。
- 统一速度规则：子集配方按总纲 §6.1 降档规则标定——`EUt = 8`、`时长 = 上游同源配方 ×2`、总能耗为上游一半。ULV = 慢而省电，LV = 快而全。
- 统一外观：ULV 机壳 + 各自的工作贴图（`workableTieredHullModel`），与上游同型机器视觉血缘明显。
- 为什么是这三台：蒸汽时代没有对应物（调研 F10 已排除磨/炉/压/锻/合金/碎石），语义上又不需要高压（洗矿靠水流、拉丝与切割靠机械力）；电解槽单独成文（[primitive-electrolyzer.md](primitive-electrolyzer.md)）。

## 各机配方子集

### 超低压洗矿机（越级风险最高，边界最严）

| 子集 | 收录 | 明确排除 |
| --- | --- | --- |
| **收录** | 脏尘 → 尘（洗净线，如红石?、方铅矿尘除杂等逐条核对后列入）；碎石洗选类 | **矿石 → 洗净矿（选矿富集链）全族**：矿石级原料永远不进本机 |
| 语义 | 洗手、洗工具、洗粉尘的「水槽」 | 矿物倍增链条的入口仍锁在 LV |

- 越级风险声明：上游洗矿机是 LV 矿物链的一环（impure → pure）。本机只吃**已完成一次破碎后的粉尘净化**，把「矿物链第一步（破碎）已在蒸汽时代存在」与「链第二步（洗净）下沉」区分开；矿物倍增（热离心、筛选）永不下沉。若实测发现这仍让 LV 洗矿机失去存在感，砍掉本机（开放问题 1）。

### 超低压线材轧机

| 子集 | 收录 | 明确排除 |
| --- | --- | --- |
| **收录** | 常用金属板 → 线（红合金、铜、铁、锡、铅、锌等逐条列入），替代「剪线钳手工裁板」的手工线 | 合金线材需先有对应板材，规则同上游；线圈 16 线打包产物保持与上游一致 |
| 语义 | 把「1 板 → 2 线」的手工苦役变成 8 EU/t 的慢速自动化，ULV 电线铺设量的产能保障 | 无 |

### 超低压切割机

| 子集 | 收录 | 明确排除 |
| --- | --- | --- |
| **收录** | 板 → 杆/栓/齿轮坯等基础切割件（逐条列入，与上游同配方同产出、仅降档换算） | 晶圆、宝石切割等精密语义（MV+） |
| 语义 | 早期自动化小件（齿轮、杆）的产能件，替代锻锤手工路线 | 无 |

### 子集表维护规则

- 三张子集表就是定案对象：**代码只注册表内条目，扩表必须先改本文档**。
- 每条子集配方在上游同源配方基础上机械换算（EUt 8 / 时长 ×2 / 输入输出不变），禁止顺手调产出。

## 数值草案（三机通用）

| 参数 | 值 |
| --- | ---: |
| 电压 | 8 EU/t（VA 7） |
| 能量缓存 | 96 EU（12 t 缓冲，同 [primitive-electrolyzer.md](primitive-electrolyzer.md)，联动调参） |
| 处理槽 | 与上游同型机器一致（洗矿 1+1 流体进 / 1 出；轧机 1 进 1 出；切割 1 进 2 出） |

## 合成草案（工作台，三机统一骨架）

三机一律以**超低压电动马达**（[ulv-components.md](ulv-components.md)）为公共前置——洗矿机滚筒、轧机辊轮、切割锯片都是「马达带着转」的机械语义，与发电机的探测器前置（电子语义）分线。

| 机器 | 材料 |
| --- | --- |
| 洗矿 | 超低压电动马达 ×1 + 红合金单线 ×2 + 铁板 ×4 + 水桶 ×1 + ULV 机械方块 ×1 |
| 轧机 | 超低压电动马达 ×1 + 红合金单线 ×2 + 铁板 ×4 + 钢杆? ×2 + ULV 机械方块 ×1 |
| 切割 | 超低压电动马达 ×1 + 红合金单线 ×2 + 铁板 ×4 + 锯片（钢）×1 + ULV 机械方块 ×1 |

## 与既有内容的边界

- 三机终身不做 II 档（「超低压 II」不存在）；想快请用上游 LV 机。
- 不做蒸汽驱动版本（蒸汽侧已有自己的机器家族，见调研 F10；湿式蒸汽矿物处理是姊妹项目已划定的语义）。
- 不给三机添加流体自动输出、覆盖板之外的任何智能。

## 实现要点（API 映射）

- 三机均为 `SimpleTieredMachine` + `tier(GTValues.ULV)` + 各自 `GTRecipeType`；GUI 沿用上游可编辑 UI 模板。
- 子集配方的数据生成器中逐条注释对应的上游配方 ID，保证换算可审计。

## 开放问题

1. **洗矿机的存亡判定**（本批次最大风险）：实现后统计 LV 洗矿机的使用率预期；若 ULV 洗矿让「LV 才洗矿」的节奏消失，砍掉洗矿、保留轧机与切割。
2. 洗矿收录清单的逐条核实（上游洗净线配方在 7.5.3 的完整列表）。
3. 三机能量缓存与电解槽统一为 96 EU，是否需要独立的「机器通用缓存常量」？
4. 切割机的钢锯片是否过早（钢在蒸汽时代可得但偏后期）？备选：熟铁? 锻铁锯片。
