# ULV 机器下沉（ULV 线材轧机 / 切割机 / 卷板机 / 车床）设计规格

> 状态：**已裁决草案（v0.3，2026-09-07）；v0.5 扩表（2026-09-08，所有者指示增补卷板机/车床）** · 优先级：**P1** · 类型：单方块 ULV 机器（上游机器的层级变体，配方子集）
>
> 变更记录：v0.2 移除硒整流器前置，三机前置改为超低压电动马达。v0.3 依据首轮裁决：**超低压洗矿机砍除**（越级判定 A2，移入负面清单），本批收缩为两机；切割机锯片定为**锻铁**（D12）；能量缓存统一定为 **240 EU** 并抽共用常量（C3/C4）。**v0.3.1 实现期修订（2026-09-08）**：工作台配方收纳为 3×3（轧机铁板 4→3）；锯片落地为锻铁板（GTCEu 无独立锯片物品，锻铁板即锯片坯，D12 门槛意图不变）；轧机子集配方省略上游的编程电路（单一职能无档位歧义）；240 EU 缓存抽 `ULVSimpleMachine` 公共基类（与电解槽共享）。**v0.5 扩表（2026-09-08，所有者指示「增加能提升产能的单方块机器」）**：新增 **ULV 卷板机**与 **ULV 车床**，四机共用本文档约定（子集准入 / 240 EU / ×2 时长 / 终身不做 II 档）。

## 定位

把上游 LV 机器中「语义上并不高压」的两种，以**显式配方子集**的方式下沉到 ULV，让微电网有活干，同时保住 LV 的升级诱惑。

- 统一机制：两台机器全部使用**独立配方类型**（各自的新 RecipeMap），只收录本文档明确列入的配方；不挂上游配方表。
- 统一速度规则：子集配方按总纲 §6.1 降档规则标定——`EUt = 8`、`时长 = 上游同源配方 ×2`、总能耗为上游一半。ULV = 慢而省电，LV = 快而全。
- 统一外观：ULV 机壳 + 各自的工作贴图（`workableTieredHullModel`），与上游同型机器视觉血缘明显。
- 统一能量缓存：**240 EU**（约 30 t 缓冲），与原型电解槽共用同一常量（C3/C4 裁决）。
- 为什么是这两台：蒸汽时代没有对应物（调研 F10 已排除磨/炉/压/锻/合金/碎石），语义上又不需要高压（拉丝与切割靠机械力）；洗矿机因越级争议在首轮裁决中砍除（A2，见 [next-machine-candidates.md](next-machine-candidates.md) 负面清单）；电解槽单独成文（[primitive-electrolyzer.md](primitive-electrolyzer.md)）。

## 各机配方子集

### 超低压线材轧机

| 子集 | 收录 | 明确排除 |
| --- | --- | --- |
| **收录** | 常用金属板 → 线（红合金、铜、铁、锡、铅、锌等逐条列入），替代「剪线钳手工裁板」的手工线 | 合金线材需先有对应板材，规则同上游；线圈 16 线打包产物保持与上游一致 |
| 语义 | 把「1 板 → 2 线」的手工苦役变成 8 EU/t 的慢速自动化，ULV 电线铺设量的产能保障 | 无 |

### 超低压切割机

| 子集 | 收录 | 明确排除 |
| --- | --- | --- |
| **收录** | 板 → 杆/栓/齿轮坯等基础切割件（逐条列入，与上游同配方同产出、仅降档换算） | 晶圆、宝石切割等精密语义（MV+） |
| 语义 | 早期自动化小件（齿轮、杆）的产能件，替代锻锤手工路线 | 无 |

### 超低压卷板机（v0.5 新增，所有者指示「能提升产能的机器」）

| 子集 | 收录 | 明确排除 |
| --- | --- | --- |
| **收录** | 锭 ×1 → 板 ×1（红合金/铜/铁/锡/铅/锌逐条列入，有 GENERATE_PLATE 者生效） | 弯曲板等异形件 |
| 语义 | 替代锻锤产线：锻锤机 3 锭 → 2 板（0.67 板/锭），卷板机 1:1——**+50% 产能** | |

- 上游同源：`bend_<m>_to_plate`（EUt 24 = VA[LV]，时长 mass）。降档换算：EUt 24 → **7**，时长 mass → **mass ×2**（总能耗为上游一半，§6.1）。编程电路省略（同轧机口径）。

### 超低压车床（v0.5 新增）

| 子集 | 收录 | 明确排除 |
| --- | --- | --- |
| **收录** | ① 螺栓 ×1 → 螺丝 ×1（替代手工锉削）；② 剥皮原木/剥皮木 ×1 → 长木杆 ×4 + 木尘 ×1（原版八种木） | 宝石镜面（MV+ 精密语义） |
| 语义 | ① 螺丝自动化（本模组传送带/泵配方的螺丝需求内部闭环）；② 木材链：剥皮原木 → 长木杆 ×4 →（ULV 切割机）→ 木杆 ×8，附带木尘副产品 | |

- 上游同源：`lathe_<m>_bolt_to_screw`（EUt 4，时长 mass/8）→ 子集 EUt 不变、时长 ×2（mass/4）；`lathe_stripped_<wood>_log`（EUt VA[ULV]=7，160 t）→ 子集 EUt 不变（已是 ULV 档）、时长 ×2（320 t）。

### 子集表维护规则

- 两张子集表就是定案对象：**代码只注册表内条目，扩表必须先改本文档**。
- 每条子集配方在上游同源配方基础上机械换算（EUt 8 / 时长 ×2 / 输入输出不变），禁止顺手调产出。
- 上游配方清单核实已完成（2026-09-07 第二轮调研）：轧机吃锭/宝石/尘（非板）、常用线材配方 EUt 恰为 VA[ULV]=7 无需换算；切割机配方族见 [upstream-recipe-research.md](upstream-recipe-research.md) §4。

## 合成草案（工作台，两机统一骨架）

两机一律以**超低压电动马达**（[ulv-components.md](ulv-components.md)）为公共前置——轧机辊轮、切割锯片都是「马达带着转」的机械语义。

| 机器 | 材料 |
| --- | --- |
| 轧机 | 超低压电动马达 ×1 + 红合金单线 ×2 + 铁板 ×3 + 钢杆 ×2 + ULV 机械方块 ×1（v0.3.1 收纳 3×3） |
| 切割 | 超低压电动马达 ×1 + 红合金单线 ×2 + 铁板 ×4 + **锻铁锯片（锻铁板）** ×1 + ULV 机械方块 ×1（D12） |
| 卷板机 | 超低压电动马达 ×1 + 红合金单线 ×2 + 铁板 ×3 + 钢辊（钢杆）×2 + ULV 机械方块 ×1（v0.5） |
| 车床 | 超低压电动马达 ×1 + 红合金单线 ×2 + 铁板 ×4 + 锻铁车刀（锻铁板）×1 + ULV 机械方块 ×1（v0.5） |

## 与既有内容的边界

- 两机终身不做 II 档（「超低压 II」不存在）；想快请用上游 LV 机。
- 不做蒸汽驱动版本（蒸汽侧已有自己的机器家族，见调研 F10；湿式蒸汽矿物处理是姊妹项目已划定的语义）。
- 不给两机添加流体自动输出、覆盖板之外的任何智能。
- 矿物处理链整体不下沉：洗矿已裁砍（A2），热离心/筛选维持 LV（红线 §3.4）。

## 实现要点（API 映射）

- 两机均为 `SimpleTieredMachine` + `tier(GTValues.ULV)` + 各自 `GTRecipeType`；GUI 沿用上游可编辑 UI 模板。
- 子集配方的数据生成器中逐条注释对应的上游配方 ID，保证换算可审计。
