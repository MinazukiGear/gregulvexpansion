# ULV 元件线（ULV Component Line）设计规格

> 状态：**已实现（v0.4，2026-09-08，待实测）** · 优先级：**猫须探测器 P0；替代配方 P2 且禁用上游原配方（D14 裁决）** · 类型：元件物品 + 替代配方（电路深度化）
>
> 变更记录：v0.2 移除硒整流器，锗路线冻结。v0.3 依据首轮裁决——替代配方**提为 P2**并**禁用上游真空管/NAND 原配方**（D14，探测器路线成为 ULV 电路唯一入口，总纲 §3.5 原则同步修订）；探测器产出保持 ×2（D13）。**v0.3.1 实现期修订（2026-09-07，所有者指定）**：探测器配方输入定为**纯净方铅矿矿石**（`crushedPurified`，上游 ID `gtceu:purified_galena_ore`），替代草案中「矿石级」表述。**v0.4 已实现（2026-09-08）**：上游 6 条原配方经 `IGTAddon#removeRecipes` 移除落地；替代配方定稿——真空管 = 探测器×1 + 玻璃管 + 红合金单线（保留上游 ID `gtceu:vacuum_tube`，经 GTDynamicDataPack 直写绕过过滤器）。**v0.4.1 修订（2026-09-08，所有者指示）**：NAND 芯片**仍按上游产线**（MV 电路装配机，好电路板/塑料电路板 + 简单 SoC + 红合金螺栓 ×2 + 锡细线 ×2 → ×8/×12，EUt/时长不变），唯一成本修改是**追加猫须探测器 ×1** 作为 D14 入口；两条配方 ID 保留上游原 ID，经 GTDynamicDataPack 直写（与真空管同手法）。**v0.4.2 补充（2026-09-08，所有者指示）**：真空管恢复上游**红合金流体**两条装配机配方（玻璃管 + 钢螺栓 + 铜/退火铜单线 ×2 + 红合金流体 18L + 探测器 ×1 → ×3/×4，EUt VA[ULV]、40t 原值）——产率梯度 工作台 ×1 → 红合金 ×3 → 退火铜 ×4 与上游完全一致；两条 ID 保留上游原 ID，动态包直写。**v0.4.3 修订（2026-09-08，所有者指示）**：真空管工作台配方同样改为「上游原版 + 追加探测器」——钢螺栓 ×2 + 玻璃管 + 铜单线 ×3 + 探测器 ×1 → ×1（此前误将红合金线/改料引入工作台配方）。至此 D14 替代配方的统一原则确立：**上游配方原样保留，仅追加探测器作为唯一成本修改**。

## 定位

上游 ULV 电路只有真空管与 NAND 芯片两件成品（调研 F5），从「挖到方铅矿」到「造出 NAND 芯片」几乎没有过程深度。本线为 ULV 电路补充**元件层**。

- 设计立场：**不新增 ULV 成品电路层级**（上游 `ULV_CIRCUITS` 标签仍只有真空管、NAND 芯片两件）；补的是成品下面的元件与通往它们的路线。
- **电路唯一入口（D14 已裁决）**：上游真空管/NAND 原配方将被移除（`IGTAddon#removeRecipes`），两件成品的唯一制法是本文档的探测器替代路线——ULV 电路从「两步成品」变成「方铅矿 → 探测器 → 成品」的一条有深度的产线。这是对总纲 §3.5「不修改上游」原则的明示例外（原则已修订：所有者裁决可移除指定上游配方）。
- 历史锚点：猫须探测器（方铅矿晶体 + 金属触须，1874 年）是史上第一个半导体器件，天然兼任 ULV 级整流/检波元件。

## 需求闭环图（D14/D15 裁决后更新）

```text
方铅矿(GTCEu已有) ─蒸汽磨机─▶ 碎方铅矿 ─炼药锅手洗─▶ 纯净方铅矿矿石 ─工作台─▶ 猫须探测器 ─┬─▶ 手摇发电机 ×1（零电门槛，P0）
                                        ├─▶ 超低压电动马达 ×1（马达分发至全部 ULV 机器与温差/红石发电机，见 ulv-components.md）
                                        ├─▶ 原型电解槽 ×2（整流桥语义）
                                        └─▶ 真空管 / NAND 芯片（唯一制法，原配方已禁用，D14）
```

- 闭环自检：探测器的洗矿前置由上游原生的**炼药锅手洗**达成（调研 F13，无需任何机器）→ 手摇发电机与马达的门槛不受伤；产出 ×2（D13 已裁决）对冲「唯一入口」带来的需求上涨。

## 配方草案

### 猫须探测器（工作台，v0.3.1 实现期修订定稿）

| 输入 | 输出 |
| --- | --- |
| 纯净方铅矿矿石 ×1 + 红合金单线 ×1（细线触须） | 猫须探测器 ×2 |

- 输入为**纯净方铅矿矿石**（`crushedPurified`，`gtceu:purified_galena_ore`，2026-09-07 所有者指定）：方铅矿是 GTCEu 最早期可采的矿石之一（调研 F7），经蒸汽磨机→碎方铅矿→**炼药锅手洗**→纯净矿石，洗矿步骤引入「矿石要提纯才有电」的序章教学。
- **零电力核查（v0.3.1 更新，2026-09-07 所有者确认）**：碎方铅矿可用**水炼药锅右键手洗**成纯净方铅矿矿石（调研 F13：`GTItems#cauldronInteraction` + `GTMaterialItems.purifyMap` 的 `crushed → crushedPurified` 映射，整组 1:1 转换并消耗 1 格水位）——零电起步链**本模组单包自洽**，不依赖姊妹项目；GSE 大型蒸汽洗矿机仅作为后续自动化规模化的可选项。

### 上游成品的替代配方（P2，禁用原配方后成为唯一制法；D14 已裁决）

| 成品 | 替代路线（唯一制法） | 设计意图 |
| --- | --- | --- |
| 真空管 | 猫须探测器 ×1 + 玻璃 + 红合金路线（与上游原配方等成本对标后定稿） | ULV 电路的「电子管」入口 |
| NAND 芯片 | 上游产线不变（好/塑料电路板 + 简单 SoC + 红合金螺栓 ×2 + 锡细线 ×2，MV 电路装配机 → ×8/×12）+ **猫须探测器 ×1**（v0.4.1） | ULV 电路的「逻辑」入口 |

- **原配方禁用**：通过 `IGTAddon#removeRecipes` 移除上游真空管/NAND 的原有配方（ID 清单在实现前核实，见 [open-questions.md](open-questions.md) 待办调研）。
- 成本基准：替代配方与被移除的原配方**成本持平或略低**（±10%）；探测器 ×2 产出（D13）保证单件探测器的边际成本足够低。
- 移除原配方是总纲 §3.5 原则的明示例外（所有者 2026-09-07 裁决），存档兼容性风险（已按原配方半成品生产的场景）评估为可忽略——GT 配方移除只影响新合成。

## 已冻结/已移除路线（决策记录）

| 路线 | 状态 | 原因 |
| --- | --- | --- |
| 硒整流器（Selenium Rectifier） | **移除**（2026-09-07） | 项目所有者决定硒材料不做考虑；发电机/电解槽前置改由猫须探测器承担 |
| 锗二极管（Germanium Diode） | **冻结** | 调研证实 GTCEu 7.5.3 中锗为「注册但不可获取」：无矿石、无配方、无副产表（第二轮调研 C）；重启需先自行设计锗获取路线（涉及世界生成/副产表扩展），超出本模组范围 |

## 与既有内容的边界

- 不新增「ULV 电路」成品、不新增电路板层级（树脂电路板已是 ULV 板，调研 F5）、不做 SMD（MV+ 语义）。
- 探测器不做电力损耗、耐久、老化等模拟属性；不做「灵敏度」「检波成功率」之类的随机机制。

## 实现要点（API 映射）

- 探测器为普通 Registrate 物品（无 ElectricStats）；替代配方在 `addRecipes` 数据生成器中新增。
- **原配方移除**走 `IGTAddon#removeRecipes(Consumer<ResourceLocation>)`（调研 I：该钩子即上游提供的配方移除入口）；待移除配方 ID 清单实现前核实并登记在本文档。
- 元件标签：新建 `gregulvexpansion:ulv_components` 可选标签便于配方归类，不强制。
