# 温差发电机（Thermoelectric Generator）设计规格

> 状态：**已裁决草案（v0.3，2026-09-07）** · 优先级：**P1** · 类型：发电机（单方块，无燃料消耗、环境交互）
>
> 变更记录：v0.2 移除硒整流器前置；补充上游 ULV 太阳能覆盖板事实。v0.3 依据首轮裁决——**首批加入低温热源档**（D5）；不做维度加成（D6）；岩浆源+贴水 = 5 EU/t 封顶确认（C2）；合成前置由猫须探测器改为**超低压电动马达**（D15）；并入统一视觉家族（D7）。

## 定位

温差发电机把「贴着热的东西」变成免维护的基础负荷，是玩家从人力（手摇）迈向常设微电网的第一步。

- 免维护：不烧燃料、不吃蒸汽、无需玩家在场，放在那里就有电——但功率封顶极低。
- 主题价值：引入「热电偶」这个真实历史上与早期电力共生的概念（Seebeck 效应，1821 年）。
- 与其他发电机的分工：手摇 = 应急人力；温差 = 固定低功率保底；红石 = 可堆叠的自动化燃料电。温差的上限被环境条件锁死，不与任何燃料电竞争。

## 上游现状与空白

- GTCEu 7.5.3 无任何利用环境热的发电设备（调研 F3）；唯一的 ULV 产电物是上游太阳能覆盖板 `ulv_solar_panel`（白天 8 EU/t 直接入网，调研 B1），但它是「贴在机器上」的覆盖板语义，不提供独立发电机——本机定位不受影响，但边界节需与其区分。
- GTCEu 的 `STEAM_SOLAR_BOILER` 证明「环境交互型设备」在上游有先例，本机语义兼容。

## 运行机制

每 tick 扫描方块六个相邻面，统计热源与冷源，按「热源档位 × 冷面系数」计算输出，封顶 8 EU/t、1 A。

### 热源档位（D5 已裁决：首批含低温档）

| 相邻热源 | 每面贡献 |
| --- | ---: |
| 岩浆源块 | 4 EU/t |
| 火（fire 方块） | 2 EU/t |
| 篝火 | 1.5 EU/t |
| 火把/灯笼 | 1 EU/t |
| 熔岩流体（流动态） | 0（不可靠，不计数） |

（篝火档为 D5 裁决新增，数值 1.5 为草案起点，实现期可在 1–2 区间微调；其余低温档如需扩展先改本表。）

### 冷面系数（草案）

| 相邻冷源 | 系数 |
| --- | ---: |
| 无冷源 | ×0.5 |
| 水源块、流动水 | ×1.0 |
| 冰/雪块、雪层 | ×1.25 |

**计算式**：`输出 = min(最高单面热源档位 × 冷面系数, 8 EU/t)`。多个热面取最高档、不叠加；多冷面取最高系数。

### 数值示例

| 摆法 | 输出 |
| --- | ---: |
| 贴岩浆源块，无冷面 | 2 EU/t |
| 贴岩浆源块 + 贴水 | 4 EU/t |
| 贴岩浆源块 + 贴冰 | 5 EU/t |
| 贴火 + 贴水 | 2 EU/t |

### 设计约束

- **永动但封顶**：岩浆源块方案（最高 5 EU/t）是免费的永久电，输出必须显著低于 8 EU/t，使「想要满 8 EU/t」的玩家转向红石发电机；封顶值 5 留出红石发电机的生存空间（C2 已裁决）。
- 岩浆源块不消耗；不提供「吞岩浆桶」的主动模式（若未来需要，进候选池，见 [next-machine-candidates.md](next-machine-candidates.md) C4）。
- 不与姊妹项目热存储方块直接联动（其热库语义为蒸汽侧），联动方案进开放问题。

## 合成草案（工作台）

| 配方 | 材料 |
| --- | --- |
| 本体 | 超低压电动马达 ×1 + 红合金单线 ×2 + 铁板 ×4 + 铜板 ×2 + ULV 机械方块 ×1 |

- 前置**超低压电动马达**（[ulv-components.md](ulv-components.md)，D15 已裁决：发电机与用电机器统一以马达为公共前置，手摇发电机例外）。
- 外观并入「ULV 发电机组」视觉家族（D7 已裁决）：与红石发电机同机壳、顶部标识区分。

## 与既有内容的边界

- 不读热、不产汽，与锅炉体系零耦合；禁止后续给它加「给锅炉加热」的逆功能（越级到蒸汽侧语义）。
- 下界保护：允许把本机当作「白嫖 2 EU/t」的挂机玩具，这正是它的定位；禁止未来任何配方以温差电为**硬性前置**。

## 实现要点（API 映射）

- 自定义 `MetaMachine` 子类；输出复用能量发射容器（8 V 1 A）。
- 邻面扫描每 20 t 执行一次（而非每 t），方块更新事件触发即时重扫；不缓存方块引用以防泄漏。
- 客户端显示：顶面粒子（热面冒烟、冷面结霜）作为低成本视觉反馈，可后置。

## 开放问题

v0.3 首轮裁决后全部关闭（C2 岩浆强度、D5 低温档、D6 维度加成）。残余实现期验证项：篝火档 1.5 EU/t 数值微调（1–2 区间）、贴面扫描频率（每 20 t）的性能够否。
