# 原始蒸馏塔（Primitive Distillation Tower）与 ULV 石油线设计规格

> 状态：**已实现（v1.3，2026-09-16，待整线回归）：全部多方块、蒸馏塔框架、控制器工作台配方与 §2–§6 工艺配方均已注册** · 类型：无电多方块 ×2（蒸汽驱动）+ ULV 多方块泵 + 配套机器追加
>
> 变更记录：v1.0–v1.2.1 完成 ULV 石油线、多方块与工艺配方。**v1.3（2026-09-16）**：三个多方块的几何结构与仓口规则改为对应上游机器的完整模板；随后按所有者修订将蒸馏塔限制为最高 6 层、裂化机线圈替换为钢制燃烧室、钻井机钢框架替换为青铜框架。

## 1. 定位

「前电力时代工业遗迹」第五件套（原始高炉/原始泵/焦炉/铅室之后）：**用原始工艺从油砂里蒸出石油组分，并在 ULV 时代强制打通聚乙烯合成**。

- 原始蒸馏塔与 ULV 化学反应釜/流体固化器组成 ULV 石油线：原油（钻井机）→ 硫化组分 → 脱硫 → 裂化乙烯 → 聚乙烯。
- 铁律修订（随本规格生效）：准入原则增补「**无电原始多方块特例**」——可下放 HV 级配方，但必须时长拉伸 ≥×16 且蒸汽驱动，确保完全无法替代电力产线（铅室先例口径的延伸）。
- 诚实边界：分馏产物的大宗消费者（燃烧发电机/气轮机/聚合规模化）为 LV/MV 机器——ULV 石油线的产出以**储备与塑料板**为主，产业规模属 HV 蒸馏塔。

## 3. 原始蒸馏塔（本体）

| 项目 | 值 |

| 中文名 | 原始蒸馏塔 |

| 控制器类 | `machine.multiblock.PrimitiveDistillationTowerMachine`（WorkableMultiblockMachine） |
| 配方类型 | `GULVRecipeTypes.PRIMITIVE_DISTILLATION`（新注册，group `MULTIBLOCK`） |
| 结构方块 | 蒸馏塔框架（`distillation_frame`，新方块，钢链可造） |

### 结构

- **沿用上游蒸馏塔的 3×3 可重复塔身，最高 6 层**：底层放控制器和流体输入仓，中空塔身段可重复，顶部封顶；关闭扩展朝向并按高度排序仓口。
- 只接受流体输入；原油与蒸汽从底层仓口送入。每个塔身层最多安装 1 个单槽流体输出仓，以分层收集四种馏分。
- 与上游蒸馏塔的区分只在材料、供能与数值：主体改用蒸馏塔框架，无电蒸汽驱动，产量配方拉伸 ×16。

### 本体配方（无电，蒸汽驱动；产出比例与上游一致；**工艺配方未注册，§8 待确认**）

| 输入 | 产出 | 时长 |
| --- | --- | ---: |
| 原油 50 mB + 蒸汽 2,560 mB（8 mB/t × 320t 一次扣除） | 硫化重燃料 15 + 硫化轻燃料 50 + 硫化石脑油 20 + 硫化气体 60 mB | 320 |

- 上游同源：`distill_oil`（蒸馏塔，EUt 96 / 20t）。**×16 时长拉伸**（HV→无电跨四级电压，每级 ≥2×），蒸汽按运行时长一次扣除。
- **无法替代电力产线**：HV 塔同批次 20t + 1,920 EU；原始塔慢 16 倍且烧掉等值蒸汽。

## 4. ULV 流体钻井机（新增多方块，原油主获取端）

| 项目 | 值 |
| --- | --- |
| 资源 ID | `gregulvexpansion:ulv_fluid_drilling_rig` |
| 机器类 | `machine.multiblock.ULVFluidDrillingRigMachine`（多方块，ULV 电力 8 EU/t，extends 上游 FluidDrillMachine） |

- **抽取实体油田**：命名与上游 `fluid_drilling_rig` 对齐（ULV 前缀变体）。复用上游基岩流体系统（`GTBedrockFluids`：原油/轻油/重油/天然气矿脉，带产量与枯竭机制）——多方块放置在含油矿脉的区块上，缓慢产出原油并存入内部缓存/输出仓；
- **结构沿用上游流体钻井机**：3×3 底座与完整 7 格高钻架，底座至少保留 3 个蒸馏塔框架机壳，允许 1–2 个能源输入仓和至多 1 个流体输出仓；钻井架材料由上游钢框架下调为青铜框架。
- 产出速率（v1.2 按实现修正）：单钻井周期 86t @ EUt 7（无电档 VA[ULV]），单周期产出为上游 LV 钻机同周期的一半（`P/2`），折合**持续产率 ≈ LV 流体钻井机的 11.6%、单位能耗 ≈ 2 倍**；矿脉枯竭机制与上游一致；
- 与油砂路线并存：油砂为挖掘型补充来源（流体提取机榨取），超低压流体钻井机为持续型主来源。

## 7. 聚乙烯链闭环图

```text
超低压流体钻井机（实体油田，8 EU/t）
 → 原油
 → 原始蒸馏塔（无电+蒸汽）→ 硫化重/轻燃料/硫化石脑油/硫化气体
 → ULV 化学反应釜·脱硫（+电解氢）→ 轻燃料/石脑油/**重燃料**（+H₂S）
 → 原始裂化机（+蒸汽）→ 乙烯
 → ULV 化学反应釜·聚合（+氧/空气）→ 聚乙烯流体
 → ULV 流体固化器（+板模具）→ 聚乙烯板
```

- **诚实边界**：聚乙烯板/流体的上游消费者（微处理器、NAND 芯片、塑料电路板→MV/HV 电路线）全部在 LV+；ULV 石油线的价值 = 储备原料、打通化学工艺流、为跨入 LV 提前铺路。
- **塑料电路板不收录**（所有者指示）：塑料电路板→NAND 仍卡 SoC，ULV 阶段无法消费；该配方留给上游 LV/MV 产线。
