## 一、判断依据

1. **是否填补上游空白**：GTCEu 7.5.3 的 ULV 层只有机壳/变压器/能量仓/电池缓冲/充电站（调研 F2），机器与发电机全空——候选应优先落在这个空白带。
2. **是否与蒸汽时代重复**：蒸汽已有磨/炉/压/锻/合金/碎石/采矿（调研 F10），任何候选不得与之一一对应。
3. **是否越级**：候选触碰 LV/MV 语义（选矿富集、熔盐电解、并行加工）时需给出显式配方子集，否则降级。
4. **是否放大产能**：凡提供并行、超频、规模化语义的候选，默认 P3（违反「ULV 不做放大」红线，除非给出强叙事理由）。
5. **上游重叠风险**：候选与上游已有物品/工具语义重叠时，必须写出差异化边界，写不出就砍。

## 三、已明确不做（负面清单）

| 条目 | 理由 |
| --- | --- |
| ULV 版蒸汽机器（磨/炉/压/锻/合金/碎石/采矿） | 与蒸汽时代机器一一重复（调研 F10），红线 §3.2 |
| ULV→LV 变压器、ULV 电池缓冲、ULV 充电站、ULV 能量仓 | 上游已全部存在（调研 F2），重复造轮子 |
| 矿物倍增下沉（热离心/筛选的 ULV 版） | 选矿富集链是 LV 核心诱惑，越级红线 §3.4 |
| 熔盐电解（铝/镁/钠） | LV/MV 语义，永久禁止（[primitive-electrolyzer.md](primitive-electrolyzer.md) 子集准入） |
| 任何并行/超频/规模化机制 | ULV 不做放大（总纲 §3.3），产业升级的收益必须留给 LV+ |
| ULV 太阳能发电方块/原型 | 上游已有 `ulv_solar_panel` 覆盖板（8 EU/t 直接入网，调研 B1），语义重复（原 C3） |
| 锗系元件（锗二极管等） | 锗在 7.5.3 无任何获取途径；重启前需先立项锗获取路线（原 C7） |
| 硒系元件（硒整流器、硒光电池） | 项目所有者决定硒材料不做考虑（2026-09-07），相关设计已从各文档移除 |
| 小型蒸汽轮机（蒸汽变现单方块） | **A1 首轮裁决砍除**（2026-09-07）：LV 蒸汽轮机可被玩家廉价跳造，ULV 版缺乏生存空间；蒸汽变现语义由温差/红石发电承接，蒸汽消费仅保留铅室 |
| 超低压洗矿机 | **A2 首轮裁决砍除**（2026-09-07）：「不纯尘→纯净尘」下沉破坏「LV 才洗矿」的升级阶梯；矿物处理链整体不下沉（红线 §3.4），ULV 产线收缩为轧机/切割机/电解槽 |
