# 0.1.0 Alpha 1 验收

Alpha 验收统一使用 Forge GameTest。`runGameTestServer` 必须发现至少一项测试，且日志必须同时包含完成数量和“全部必需测试通过”；否则 Gradle 任务失败。

## GameTest 覆盖

- [x] 手摇发电机初始无曲柄，空手右键不产电。
- [x] 木质曲柄可安装且生存模式恰好消耗一个；安装后每次产生 120 EU，10 tick 冷却有效。
- [x] 破坏一台已安装曲柄和一台空机器时，只掉落一个曲柄。
- [x] 基础构件的上游式工作台配方及三种橡胶路线均已加载，旧的单一路线不存在。
- [x] 化学反应釜覆盖聚乙烯、天然橡胶及酸/脱硫链；流体固化器覆盖聚乙烯和橡胶的锭、粒、块、板及五档聚乙烯流体管。
- [x] 单方块机器统一使用“原始”命名；中英文语言键一致；机器 tooltip 使用上游模板；自定义配方分类有中文名称。
- [x] ULV 构件和机器的关键速率、容量、发电量及钻井周期固定为审定值。
- [x] 铅室预览包含青铜管道机壳及恰好一个钢制燃烧室，并能按 EMI 预览成型。
- [x] 原始蒸馏塔四种高度均能成型，最高尺寸为 6 层。
- [x] 原始裂化机使用钢制燃烧室并能成型；流体钻井机使用青铜框架、不含钢框架并能成型。

## 发布检查

```powershell
.\gradlew.bat runData
.\gradlew.bat runGameTestServer
.\gradlew.bat clean build
```

`clean build` 同时校验 JSON、工作台配方符号、中英文键、模型引用、发布 JAR 元数据、许可证文件及构建缓存泄漏。
这些规则集中在 `gradle/verification.gradle`，由主 `build.gradle` 引入；新增校验应继续放在该文件，避免主构建脚本重新膨胀。

Java 编译启用 `-Xlint:all,-classfile,-processing`：检查项目源码的弃用、泛型、覆写和资源管理等问题，同时过滤 GTCEu 已编译 class 中缺失可选注解造成的第三方噪声。Gradle 8.8 必须使用 JDK 17 运行。
