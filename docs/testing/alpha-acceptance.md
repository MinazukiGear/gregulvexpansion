# 0.1.0 Alpha 验收清单

本清单用于每个 Alpha 候选版本。自动检查必须全部通过；实机项目由测试者在全新世界中逐项确认。

## 自动检查

- [x] `runData` 成功，生成资源无漂移错误。
- [x] `validateGeneratedResources` 通过：JSON 可解析、工作台有序配方符号完整、中英文键一致。
- [x] `clean build` 成功，发布 JAR 可生成。
- [x] 连续两次干净构建产物 SHA-256 一致；`verifyReleaseJar` 检查版本、许可证、署名和构建缓存泄漏。
- [x] `runGameTestServer` 完成双端注册、数据包与配方加载。
- [x] `runClient` 完成主菜单资源加载。

## 实机流程

- [ ] 手摇机：40 次有效摇动充满 4,800 EU；冷却期间点击不产电；满缓存支持 8 EU/t 负载 600 tick。
- [ ] 曲柄：木质曲柄和 AE2 曲柄均可安装；扳手拆卸会掉落曲柄；破坏已安装机器不会复制或吞掉曲柄。
- [ ] 微电网：温差、红石、燃气发电机输出及铅酸蓄电墙充放电、过压熔断符合提示。
- [ ] 基础机器：各 ULV 机器只能显示并运行审定子集，输入输出与文档一致。
- [ ] 构件覆盖板：传送带、泵、机械臂、流体调节器的速率、方向和过滤行为正确。
- [ ] 多方块：铅室、原始蒸馏塔、原始裂化机、流体钻井机结构均可成型，仓口限制正确。
- [ ] 石油线：钻井输出受阻后可恢复；区块重载后继续工作；矿脉产量随枯竭下降；蒸馏、裂化、脱硫、聚合最终得到聚乙烯板。
- [ ] 本地化与资源：中文、英文无裸键；物品和方块模型、活动纹理、EMI 配方显示正常。
- [ ] 平衡：记录硫粉主世界积累速度，并决定铅室硫耗是否需要调整。
